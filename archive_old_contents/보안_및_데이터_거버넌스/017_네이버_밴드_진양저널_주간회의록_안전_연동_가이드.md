        <h2 class="display-lg hairline-bottom">네이버 밴드 ↔ 진양저널 연동 정석 가이드</h2>
        
        <p class="body-text">이 문서는 네이버 밴드에 기록된 <strong>'주간 회의록 및 일정표'</strong>를 진양저널 시스템으로 안전하고 정확하게 수집(Pull)하는 <strong>최적의 실무 파이프라인과 규칙(SOP)</strong>을 안내합니다.</p>

        <h3 class="display-md" style="margin-top: 40px;">1. 왜 이 방식이 '정석'인가? (CEO 인사이트 반영)</h3>
        <p class="body-text">초기에는 "현장 사진만 밴드에 올리면 AI가 알아서 회의록을 써주는" 완전 자동화를 고려했으나, 이는 <strong>AI의 환각(거짓 정보 생성) 리스크</strong>와 <strong>보안 유출 위험</strong>이 컸습니다. 따라서 <strong>'밴드에 먼저 명확한 텍스트를 작성하고, 이를 수집하는 방식'</strong>으로 선회했습니다.</p>
        
        <div class="grid" style="display: grid; grid-template-columns: 1fr 1fr; gap: 16px; margin-top: 24px;">
            <div class="card" style="padding: 20px; border: 1px solid var(--hairline); border-radius: var(--rounded-md); background: var(--canvas-parchment);">
                <div class="body-strong" style="color: var(--primary); margin-bottom: 8px;">환각(Hallucination) 제로화</div>
                <p class="caption">사진의 불완전한 맥락을 AI가 상상해서 채우지 않도록, 직원이 직접 작성한 '확정된 텍스트'만 가져오므로 오류가 0%에 수렴합니다.</p>
            </div>
            <div class="card" style="padding: 20px; border: 1px solid var(--hairline); border-radius: var(--rounded-md); background: var(--canvas-parchment);">
                <div class="body-strong" style="color: var(--primary); margin-bottom: 8px;">단일 진실 공급원 (SSOT)</div>
                <p class="caption">소통의 중심인 '네이버 밴드'가 기준 데이터가 되고, 진양저널은 이를 영구 보관(Archive)하는 역할로 명확히 분리됩니다.</p>
            </div>
        </div>

        <h3 class="display-md" style="margin-top: 50px;">2. 실무 적용을 위한 밴드 작성 규칙 (SOP)</h3>
        <p class="body-text">프로그램을 복잡하게 만드는 대신, <strong>직원들이 밴드에 글을 올리는 가벼운 약속</strong>을 통해 자동화를 완성합니다.</p>
        
        <div style="background: var(--surface-tile-1); color: var(--on-dark); padding: 24px; border-radius: var(--rounded-lg); margin: 20px 0;">
            <p class="body-strong" style="margin-bottom: 12px; color: var(--primary-on-dark);">📌 밴드 주간보고 작성 템플릿</p>
            <pre style="background: transparent; color: var(--on-dark); font-family: 'SF Pro Text', monospace; font-size: 14px; margin: 0; line-height: 1.6;">#진양저널_주간보고

[일정표]
- 7/20(월): A구역 건축심의 준비
- 7/22(수): B구역 조합 회의

[회의록]
- 지하주차장 모듈 8.4m 적용 확정
- 데크 레벨 산정 재검토 필요
(여기에 필요한 현장 사진 첨부)</pre>
        </div>

        <h3 class="display-md" style="margin-top: 40px;">3. 진양저널 API 수집 파이프라인 (Python 로직)</h3>
        <p class="body-text">위 규칙을 바탕으로 진양저널 서버는 <strong>매주 월요일</strong>에 다음과 같은 로직을 수행합니다.</p>
        
        <ul style="margin: 0; padding-left: 20px; font-family: 'SF Pro Text', sans-serif; line-height: 1.6;">
            <li><strong>STEP 1. 필터링 호출:</strong> 밴드 API를 통해 글을 읽어올 때, 본문에 <code>#진양저널_주간보고</code> 태그가 있는 게시글만 수집합니다. (노이즈 완벽 제거)</li>
            <li><strong>STEP 2. 파싱(Parsing):</strong> 가져온 글 본문에서 <code>[일정표]</code>와 <code>[회의록]</code> 키워드를 기준으로 텍스트를 분리합니다.</li>
            <li><strong>STEP 3. 외부 AI 통과 X:</strong> 텍스트가 이미 사람이 정제한 완벽한 상태이므로, 구글이나 OpenAI 서버에 데이터를 보낼 필요 없이 즉시 J 저널 마크다운으로 변환합니다. (보안성 최고 등급)</li>
            <li><strong>STEP 4. 자동 저장:</strong> 진양저널의 특정 폴더(예: 주간회의록)에 새 마크다운 파일로 영구 저장합니다.</li>
        </ul>
