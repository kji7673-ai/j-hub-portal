<h3>데이터 생태계의 기반: 서버(Server)란 무엇인가?</h3>

<figure class="figure-center">
  <img src="static/images/illustrations/cloud.jpg" alt="물리적 서버와 클라우드 서버의 대비" class="figure-img">
  <figcaption class="figure-caption">[삽도] 무거운 물리적 서버(On-Premise)를 넘어 유연한 클라우드 생태계로의 전환</figcaption>
</figure>

<p>서버란 데이터를 저장하고 네트워크를 통해 사용자에게 서비스를 제공하는 고성능 컴퓨터입니다. 우리가 스마트폰으로 진양저널을 확인하거나 정비사업 통합검토를 실행할 때, 그 요청을 받아들여 결괏값을 보내주는 두뇌 역할을 합니다.</p>

<h4>1. 일반 서버 (On-Premise)</h4>
<p><strong>개념:</strong> 회사 내부 전산실이나 사무실 한편에 물리적인 컴퓨터 장비(하드웨어)를 직접 사서 두고 관리하는 방식입니다.</p>
<div class="alert alert-secondary">
<ul>
    <li><strong>장점:</strong> 장비를 직접 통제하므로 보안 환경을 완전히 물리적으로 독립시킬 수 있습니다.</li>
    <li><strong>단점:</strong> 초기 구축 비용이 엄청나게 비싸며, 정전이나 화재 시 서비스가 완전히 중단됩니다. 외부(모바일)에서 접속하기 위해서는 복잡한 VPN 설정 등이 필요합니다.</li>
</ul>
</div>

<h4>2. 클라우드 서버 (Cloud Computing)</h4>
<p><strong>개념:</strong> 아마존(AWS), 마이크로소프트(Azure), 구글(GCP) 같은 글로벌 IT 기업이 전 세계에 지어놓은 거대한 데이터 센터의 자원을 인터넷을 통해 필요한 만큼 빌려 쓰는 방식입니다.</p>
<div class="alert alert-info">
<ul>
    <li><strong>장점:</strong> 초기 비용이 0원에 가깝고(사용한 만큼만 지불), 인터넷만 연결되면 전 세계 어디서든 모바일로 접속이 가능합니다. 트래픽이 몰려도 버튼 하나로 성능을 무한대로 늘릴 수 있습니다.</li>
    <li><strong>단점:</strong> 데이터를 외부에 보관하므로 강력한 인증 및 권한 관리가 필수적입니다.</li>
</ul>
</div>

<h4>💡 진양저널이 클라우드를 선택한 진짜 이유</h4>
<p>진양엔지니어링의 소통 허브인 <strong>'진양저널'은 왜 사내 PC가 아닌 GitHub Pages와 같은 글로벌 클라우드에 배포되었을까요?</strong></p>
<ol>
    <li><strong>시공간의 제약 파괴 (Mobile First):</strong> 현장 조사 중이거나 출퇴근 중에도 스마트폰으로 회사의 공지사항과 메뉴얼을 즉시 열람해야 하기 때문입니다. 사내망(On-Premise)에 가두면 외부 접속이 차단되어 '소통의 단절'이 발생합니다.</li>
    <li><strong>무중단 서비스 (High Availability):</strong> 사내 정전이나 사무실 인터넷 장애가 발생하더라도, 클라우드에 배포된 진양저널은 24시간 365일 결코 멈추지 않습니다.</li>
    <li><strong>유연한 트래픽 대응:</strong> 향후 진양저널의 규모가 커지고 복잡해지더라도 즉각적으로 서버 자원을 증설할 수 있는 유연성을 확보하기 위함입니다.</li>
</ol>

<div class="alert alert-secondary" style="margin-top:24px;">
    <h4>☁️ 실제 도입 효과 및 보안성</h4>
    <p>클라우드 서버 도입 후 진양엔지니어링이 체감한 가장 큰 변화는 '어디서든 접근 가능하다'는 편리함 이면에 숨겨진 강력한 보안 통제권입니다. 일반 서버에서는 물리적 탈취 위험과 랜섬웨어 감염 시 복구가 불가능한 치명적 단점이 존재했습니다.</p>
    <ul>
        <li><strong>자동 백업 및 복원:</strong> 매일 자정 스냅샷 기반 백업을 통해 데이터 유실 리스크 99% 감소.</li>
        <li><strong>엔드포인트 보안:</strong> IAM 기반 접근 제어를 통해 인가되지 않은 외부 접속 차단.</li>
        <li><strong>비용 효율성:</strong> 온프레미스 서버 유지보수 대비 TCO(총 소유 비용) 30% 절감.</li>
    </ul>
    <p>💡 <strong>교훈:</strong> 클라우드는 단순히 데이터를 외부에 저장하는 것이 아닙니다. 최고 수준의 보안 인프라를 임대하는 것과 같습니다.</p>
</div>
