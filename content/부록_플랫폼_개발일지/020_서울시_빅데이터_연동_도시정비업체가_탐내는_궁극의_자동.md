<h3>서울시 빅데이터 연동: 도시·정비업체가 탐내는 궁극의 자동 추출 도구</h3>

<h4>2. 서울 열린데이터광장 API 호출 예시</h4>
<p>서울시 정비구역 현황 데이터를 자동 수집하는 Python 코드입니다.</p>
<pre style="background:#2d3748;color:#e2e8f0;padding:16px;border-radius:8px;font-size:13px;overflow-x:auto;">
import requests

API_KEY = "YOUR_API_KEY"  # data.seoul.go.kr에서 발급
BASE_URL = "http://openapi.seoul.go.kr:8088"

def fetch_redevelopment_zones(gu_name="강남구"):
    """서울시 정비구역 현황 조회"""
    url = f"{BASE_URL}/{API_KEY}/json/tbLnOpendataRtmsRent/1/100/"
    params = {"GU_NM": gu_name}
    
    response = requests.get(url, params=params)
    data = response.json()
    
    zones = data.get("tbLnOpendataRtmsRent", {}).get("row", [])
    print(f"[{gu_name}] {len(zones)}건 조회 완료")
    return zones

# 실행
zones = fetch_redevelopment_zones("[A구]")
for z in zones[:5]:
    print(f"  구역명: {z.get('BJDONG_NM')} | 면적: {z.get('BLDG_AREA')}㎡")
</pre>

<h4>3. 건축물대장 API 연동</h4>
<p>건축물대장 표제부/총괄표제부를 일괄 조회하여 건물 현황을 자동 수집합니다.</p>
<pre style="background:#2d3748;color:#e2e8f0;padding:16px;border-radius:8px;font-size:13px;overflow-x:auto;">
import requests
import xml.etree.ElementTree as ET

SERVICE_KEY = "YOUR_SERVICE_KEY"

def fetch_building_ledger(sigungu_cd, bjdong_cd, bun, ji):
    """건축물대장 표제부 조회"""
    url = "http://apis.data.go.kr/1613000/BldRgstService_v2/getBrTitleInfo"
    params = {
        "serviceKey": SERVICE_KEY,
        "sigunguCd": sigungu_cd,
        "bjdongCd": bjdong_cd,
        "bun": bun.zfill(4),
        "ji": ji.zfill(4),
        "numOfRows": 100
    }
    
    resp = requests.get(url, params=params)
    root = ET.fromstring(resp.text)
    items = root.findall(".//item")
    
    results = []
    for item in items:
        results.append({
            "건물명": item.findtext("bldNm", ""),
            "주용도": item.findtext("mainPurpsCdNm", ""),
            "구조": item.findtext("strctCdNm", ""),
            "연면적": item.findtext("totArea", ""),
            "층수": f"지상{item.findtext('grndFlrCnt', '')}층/지하{item.findtext('ugrndFlrCnt', '')}층",
            "사용승인일": item.findtext("useAprDay", "")
        })
    return results

# [A구역] 36개 필지 일괄 조회 예시
parcels = [
    ("11680", "10300", "123", "4"),
    ("11680", "10300", "123", "5"),
    # ... 나머지 34개 필지
]

for p in parcels:
    buildings = fetch_building_ledger(*p)
    for b in buildings:
        print(f"  {b['건물명']} | {b['주용도']} | {b['연면적']}㎡ | {b['사용승인일']}")
</pre>

<h4>5. 데이터 정제 및 전처리 워크플로우</h4>
<p>수집된 원시 데이터를 분석 가능한 형태로 변환하는 파이프라인입니다.</p>
<ol>
  <li><strong>수집(Collect)</strong>: API 호출 → 원시 XML/JSON 저장</li>
  <li><strong>파싱(Parse)</strong>: XML → Python dict / JSON 변환</li>
  <li><strong>정제(Clean)</strong>: 누락값 처리, 날짜 포맷 통일, 면적 단위 변환(㎡↔평)</li>
  <li><strong>병합(Merge)</strong>: 건축물대장 + 지적 + 도시계획 데이터를 PNU(필지고유번호) 기준으로 JOIN</li>
  <li><strong>분석(Analyze)</strong>: 노후도 산정, 과소 필지 판별, 용적률 여유분 계산</li>
  <li><strong>보고(Report)</strong>: JSON → HTML/PDF 보고서 자동 생성</li>
</ol>
